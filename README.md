Statistical Frequency Table

A simple Python project that generates statistical frequency tables using data entered by the user or provided through a file (csv).

Features

- Handling qualitative and quantitative data.
- Calculating absolute, cumulative, and relative frequencies.
- Organizing data into frequency tables.

Technologies

- Python
- Tkinter

About
A simple project developped to practice Python programming and Object-Oriented Programming (OOP), including classes, Inheritance, and Polymorphism .

Project status: Still under development.
